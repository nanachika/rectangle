# Перенос графического движка: Turtle ➡️ Pygame


## 🚀 Стек технологий
* **Python**: 3.13.11
* **Pygame**: 2.6.1

## 🛠️ Архитектура и особенности реализации
В ходе рефакторинга были решены следующие архитектурные задачи:
1. **Полиморфизм и Абстракция**: Архитектура построена на абстрактном базовом классе `Figure` (модуль `abc`), от которого наследуются конкретные классы фигур `Rect` и `Circle`.
2. **Внедрение зависимостей (Dependency Injection)**: Графический контекст (`screen` в Pygame) сквозным образом передаётся по цепочке вызовов от главного игрового цикла до конечных функций отрисовки.
3. **Честная координатная отрисовка**: 
   * Отрисовка прямоугольников в `square.py` намеренно реализована пошагово через четыре линии `pg.draw.line` по вычисленным угловым координатам сторон. Это исключает использование "магических" готовых методов и закрепляет понимание координатной сетки Pygame.
   * Круги отрисовываются через встроенный метод `pg.draw.circle` относительно вычисленного центра.
4. **Управление жизненным циклом приложения**: Реализован классический игровой цикл (Game Loop) с безопасным переключателем флага закрытия окна (`pg.QUIT`) и корректным освобождением ресурсов через `pg.quit()`.

## 📂 Структура проекта
* `main.py` — точка входа, генерация списка случайных фигур, инициализация Pygame и главный игровой цикл.
* `figure/` — пакет с классами сущностей:
  * `fig.py` — абстрактный класс `Figure`.
  * `rect.py` — класс прямоугольника `Rect`.
  * `cirl_fig.py` — класс круга `Circle`.
* `fun/` — пакет с низкоуровневыми функциями отрисовки:
  * `square.py` — ручная сборка прямоугольника из линий `pg.draw.line`.
  * `circle.py` — отрисовка круга через `pg.draw.circle`.
